# HyprShelld User Guide

HyprShelld is a desktop environment being built specifically for Hyprland. Its
goal is to provide a polished desktop that works out of the box while remaining
configurable for experienced users.

## Current status

HyprShelld is in early development. There is not yet an installable desktop or
a supported daily-use build. The current codebase establishes and begins
validating the project's technical foundation.

This guide will grow with the product. Installation, everyday use, Settings,
customization, recovery, and troubleshooting instructions will be added only
when the corresponding behavior is implemented and verified.
